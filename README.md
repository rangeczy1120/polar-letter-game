# 极夜来信 · 项目导览

- **极夜来信.html**：双击进入四日联动游戏；`极夜来信-双击游玩.html` 是温馨世界原始入口。
- **polar-letter/**：游戏源代码、资源、模型与测试。请保持其中相对路径不变；构建脚本会在本目录生成双击游玩网页。
- **GLB模型/**：导出的三维模型。
- **三维模型查看器.html**：模型查看器。
- **场景截图/**：各阶段的游戏截图。
- **项目文档/**：功能说明、素材提示词与技术记录。
- **历史脚本/**：早期生成和验证脚本，部分包含旧机器或旧版本的绝对路径，运行前需要检查并修改路径。
- **temp/**：打包时保留的历史浏览器测试临时文件，并非游戏运行必需。

音效由 `polar-letter/audio.js` 在游戏运行时生成；素材位于 `polar-letter/assets/`。本整理版保留原始文件，源代码目录结构未变。

## 温馨与恐怖双世界

- `融合框架/`：双世界单文件构建脚本、过渡外壳和接入说明。
- `恐怖世界/`：组员交付恐怖版单文件的目录和说明。
- 温馨世界当前使用根目录的双击游玩 HTML，源代码在 `polar-letter/`。

两版结束信号和恐怖世界到位后，按 `融合框架/README.md` 配置并构建。当前温馨版尚未实现四站送信完成信号，也没有跨日持久化和最终剧情，不能视作完整故事。

四日联动的使用和重新构建方式见 `四日联动/README.md`。
