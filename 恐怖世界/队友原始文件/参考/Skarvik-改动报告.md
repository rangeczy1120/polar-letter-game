## 用户提的六件事，逐条落地

### 1. 恐怖没有递进 → 做成 5 → 7(+2) 的阶梯

| 轴 | 第 2 夜（它知道你） | 第 4 夜（它进来了） |
|---|---|---|
| 距离 | 屋外 14m / 6m / 18m / 3m | 屋内 3m / 身后 2m |
| 声源 | 窗外敲玻璃 | 门**内侧**被敲（`chKnockInside`） |
| 数量 | 1 个分身 | 3 个分身堵在门口（`chTripleDouble`） |
| 规则 | 举灯 → 问答 → 它走 | 举灯 → 光被按灭 → 它不退 |
| 视线 | 一直看得见 | 灯灭 1.1 秒，亮起来杯子换了位置 |

计数用 `CH.terror`（`flags()` 里可读）：
- 第 2 夜三封走完 = **5**：拍窗 / 极光红对峙 / 喊乳名（远） / 椅子被拉开 / 杯子倒扣
- 第 4 夜三封走完（拆信前）= **7**：进夜多一封 / 门内侧敲 / 喊乳名（近） / 灯灭杯子换位 / 两把椅子正对门 / 守则失效 / 三个分身进屋
- 拆最后一封再 **+2** = **9**：信封背面那行字 / 身后呼吸

### 2. 乳名 小满 → 丽芙（Liv）

`MONOLOGUES.callName` 的 TTS 与卡片正文都改；触发时机从「第 4 次进屋」改成按夜挂：
第 2 夜投完 B 后 2 秒（风雪里、远）；第 4 夜投完第二封 1.8 秒（屋里、就在侧后方）。
全文 `小满` 命中 **0**，`丽芙` 命中 **9**。

### 3. 《小星星》音效

- `playMusicBox()` 默认 `times` 2 → **1**（一遍 21 音 ≈ 17 秒，不再 33 秒）
- `VOL` 0.055 → **0.135**，`HARM` 0.25 → 0.30，低通 3200 → 4200
- 加 **45 秒冷却**（`mbCool`），极光反复变红也不会连着播
- 播放时把极光 drone 压到 0（`setAurora('none')`），结束/`stopMusicBox` 自动还原 ——
  这就是「相对底噪有点小」的解法：不是单纯加音量，是让底噪先退开

### 4. 五个交互修好（真因：厚交互函数全成了孤儿）

v13 收口后 `_tryInteract()` 没有调用点了，`INTERACT` 里：
`cup` / `chair` **根本没注册**；`radio` / `shelf` / `fireplace` 是 `chAmb()` 薄壳（只回一句话），
把 `playRadio()` / `inspectShelf()` / `openChoice('fireplace')` 全挡住。

现在：
| id | 改法 | 结果 |
|---|---|---|
| `radio` | 换 `chRegister` + `obj: props.radio` | 出 `— 收音机 · AM —`，三段 AM 内容可播 |
| `shelf` | 换 `chRegister` + `obj: props.shelf` | 出 `— 书架 —` 三段 |
| `fireplace` | `run` 改走 `openChoice('fireplace')` | 点火 / 添柴 / 看灰的选项面板回来了 |
| `cup` | **新增**注册（radius 1.1） | 出 `— 杯子 —`，第 2/4 夜各有新话 |
| `chair` | **新增**注册（radius 1.2） | 第 2 夜「被拉开半臂」/ 第 4 夜「正对着门」 |

顺带修的一个手感 bug：`chPickAim()` 现在遵守注册时**显式**写的 `radius`（存在 `it.rayR`），
所以隔着桌子不会把杯子的射线抢走；没写 radius 的（信箱/信）保持原语义，4.2m 外照样能投。

### 5. 火柴拾取不出来（两处都断了）

- **地上 4 根**：`matchPickables` 有生成、有光晕、有浮动，但拾取入口 `pickMatch()` **函数不存在**，
  注册表里也没有条目 → 加 `matchpick0..3` 动态注册 + 新函数 `chPickMatchUp(m)`（HUD +1、光晕熄灭）。
- **火柴盒三根**：`chAmb('matches')` 薄壳挡住 `openChoice('matchbox')` → 换成 `chRegister`。
- 顺手修：那个选项原本 `game.hand = MATCH_INITIAL.map(...)` 硬重置成 3 根，
  捡到的火柴会被打回去 → 改成「补满到 3，多了不吞」。

### 6. 信件内容

- `buildLetter2()`（第 2 夜桌上那封）：「今天不用投」→「今天还是三封 / 别看窗外 / 投完再睡，床才认你」，落款「你（今天的字比昨天抖）」
- `buildLetter()` 第 4 夜分支：五行全换（末行「不要回头。」），落款「—— 丽芙」
- `chLastLetter()`：加「信封背面有一行字。你的字。」+「丽芙，别回头。」
- `NIGHT[2].B`（湖边那条船）：改成「船不在，两道拖痕拖进林子 / 信箱里十几封全是你的笔迹 / 每一封都没拆」
- `NIGHT[2]` 取信件、`NIGHT[4]` 取信件与三张 A 卡同步重写

### 7.（追加）送信路上多撞见它 —— 7 次一闪而过

`chFlashDouble(o)`：出现 → 定格 → 到点直接 `scene.remove`。
第 2 夜 4 次（14m 背对 / 侧后 6m / 树线 18m / 门口 3m），第 4 夜 3 次（台阶 3m / 转身身后 2m / **屋内窗后**）。
7 次都**不计入 `terror`**，都不锁操作、不弹卡、不推剧情。

### 8.（追加）和分身交互时鼠标自动出来

真因两条：`pos` 的 y 是 `CH.double.y + 2.35`（浮标悬在头顶上空）且**没有 `obj`**，
平视它胸口射线必然打空；`run` 也不主动解指针锁。
现在：补 `obj: CH.double.root`、y 降到 `+1.15`、`run` 第一行 `exitPointerLock()`；
第 4 夜那三个分身也可点（`CH.step === 3 || (CH.day === 4 && CH.terror >= 7)`）。

## 与提示词的偏差（3 处，都是实现需要，已核实）

1. **多了一个小工具 `chAfterCard(fn)`**（提示词白名单 6 个函数之外）。
   它是「等卡片关掉再执行」的通用等待（250ms 轮询，最多 12 秒兜底），
   被第 2/4 夜的事件复用；没有它就得把同样 6 行轮询复制 6 遍。
2. **`terror` 的验收口径修正**：提示词原文写「第 4 夜拆信前 +9」是笔误 ——
   ⑧「信封背面那行字」和 ⑨「身后呼吸」发生在拆信之后，所以正确值是
   拆信前 **7**、拆信后 **9**，第 2 夜 5 + 第 4 夜 9 = 累计 **14**。代码与测试都按 7/9 打点。
3. **更新了两条过期断言**（不是为了让测试变绿）：
   - `I-⑨` 原来断言壁炉按 E 回「湿」，但壁炉改成了选项面板（这正是需求），
     改成断言「进入壁炉选项面板」。
   - `I-⑧` 原来靠壁炉那句「柴是湿的」侥幸通过，改成断言「不静默、有回话」。
   - 另外 `F-⑦` / `K-⑩` 补了测试准备（前者要先关掉上一段残留的选项面板，
     后者要在非结局状态下测光标），断言本身未降低。
