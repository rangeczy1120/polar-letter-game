```
第 1 天 19:40  走散、进屋、取信、投三封
     ↓ 第三封信箱：「第 2 天，换你写信了。」
```

## 四、窗外拍窗（新事件）

触发：第 1 天读到第 5 行「别看窗外。」，或第 2 天拆开那封信。

```
t=0.0  拍一下      有人敲了一下窗。
t=1.2              你没回头。
t=2.4  又一下      又一下。
t=3.8  两下        这次是两下。
t=5.6              敲窗的人很有耐心。
```

播放过程中只要玩家**看向窗**（水平夹角 < 25°，持续 0.5 秒）或按 E 看窗：
`cutAll(900)` 全场静音 1.4 秒 → 「窗上什么都没有。」→「玻璃是干净的。你昨天擦过的那块霜，又结上了。」
8 秒没看：「声音停在你数到四的时候。」（玩家只听到 4 下，会怀疑自己数错。）

## 五、声音设计（mentor 问的时候看这一节）

「以前听着想发笑」的根源：中文 TTS 被压到 `pitch 0.68`，等于慢放卡通。
本版把人声拉回正常（0.96~1.02），把「怪」全部交给射频层。**没有任何音频文件，全部 WebAudio 实时合成。**

| 音效 | 构成 | 频段 / 时长 / 音量 | 用在哪 |
|---|---|---|---|
| `playKnockOnGlass(n)` | 低频闷响 + 玻璃脆响 + 两个不协和分音 + 60ms 反射 | sine 82→46Hz / 90ms / 0.30；噪声带通 2600Hz Q6 / 18ms / 0.16；sine 1180 + 1490Hz / 0.45s / 0.05 | 拍窗 |
| `radioCarrierOn/Off` | 载波底噪 + 哼声 + 两个不同步抖动 | 噪声带通 1400Hz Q0.7；sine 58Hz / 0.012；LFO 0.7 + 2.3Hz / 0.02；总 0.055，起停 0.6s | 收音机场景前后 |
| `radioHeterodyne` | 两路正弦差 6Hz 的拍频 | sine 431 与 437Hz，各 0.012，4.4s | 电台啸叫（诡异主力） |
| `radioTuneDrift` | 锯齿波滑音 | 620→980→700Hz，带通 900Hz Q8，0.045，0.6s | 每 3~7 秒随机一次 |
| `radioSquelch` | 方波短促 + 噪声爆 | 900Hz / 35ms / 0.05；噪声 / 12ms / 0.08 | 拆句之间、开关载波 |
| `speakRadio` | 长句拆段，段间插「咔」+ 120~260ms 静默 | 音高 0.96~1.02、语速 0.88~0.96 | 所有电台台词 |

**为什么这样就不滑稽了**：滑稽来自「音高被压扁」；诡异来自「音高正常但信号不稳」。
431/437Hz 的 6Hz 拍频是真实的电台啸叫机理，人会本能觉得「这机器不在正常状态」，
而不会觉得「这人在装鬼」。转调叠在语音中间（每 2.4 秒一次），字还在继续、声音却飘走。

静默期间 `sound.muteUntil` 会挡掉所有 `setTimeout` 音效 —— 静默本身就是最吓人的一下。

## 六、交互层细节

- **双击**：`pointerdown` 间隔 < 400ms 才算；锁定态只看时间（坐标冻结），未锁定按点击位置拾取。
  一次双击只触发一次（测试 I-④/I-⑤）。E、回车、右下「查看」、浮标点击全部保留。
- **双击提示**：屏幕底部常驻一行 `双击 · 查看 ／ E 或回车也行`，永不消失。
- **浮标分侧**：`in` 9 个 / `out` 9 个 / `door` 1 个（邮袋）。人在屋外时屋内的点全隐藏，反之亦然。
  另外投影点距屏幕中心 > `min(W,H)*0.46` 也隐藏，避免贴边飘点。
- **信箱**：不是当前目标的那两只不再亮灰点（灰点会被误读成「能投」）。
- **目标信箱光柱**：0.55/0.85 半径、12m 高、`opacity 0.10`，只在对应 step 出现。
- **邮袋**：浮标 10px 暖黄 + 2.6s 扩散光环。
