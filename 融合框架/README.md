# 双世界缝合

温馨版源文件：根目录 `极夜来信-双击游玩.html`；恐怖版放在 `恐怖世界/游戏.html`。两者均需为自包含 HTML。构建脚本不会改动任何源游戏，只生成根目录 `极夜来信-双世界.html`。

1. 两组各自确认结束元素 ID：温馨版需在四站送信完成并睡觉后才显示；恐怖版需在天亮结束时显示。
2. 将 ID 填入 `config.json`，按需要调整 `cycles`（默认 4）。
3. 在本目录运行 `python build_merge.py`，双击生成的 HTML。修改任一源游戏后需要重新构建。

当前温馨版是三封活动信和随时休息，不具备四站送信完成的可靠信号，因此配置留空，构建会明确拒绝，防止提前进入夜晚。恐怖版尚未提供，无法验证它的结束信号、音效及游戏行为。外壳通过同源 srcdoc iframe 载入、可见信号轮询、切换时卸载旧世界、睁眼过渡与真实操作时恢复音频。它不会自动保存或重建子游戏状态；每次回到温馨世界都会重新载入，跨日进度、最终剧情和完整结局需双方共同定义及实现。音频自动播放受浏览器限制，不能保证无首次操作即可播放。
